# Web Design Knowledge

这是一个面向网页设计研究、拆解与复刻的知识工具包，用于持续沉淀优秀网站的设计方法、前端实现技术和可复用的 Agent 工作流。

## 主要内容

- **Web Design Knowledge**：网页布局、视觉风格、动效、交互、响应式设计、3D、WebGL、Shader、GSAP 等相关知识与案例分析。
- **Tools**：用于网站采集、技术分析、视觉取证、资源整理、验证与自动化处理的工具。
- **Skills**：可供 AI Agent 使用的标准化技能，让 Agent 能够分析网站、整理实现细节，并根据文档复刻相应效果。

## 目录结构

```text
Web-design-knowledge/
├── knowledge/   # 网页设计知识、案例和技术文档
├── tools/       # 分析、采集、验证与自动化工具
└── skill/       # 可供 AI Agent 使用的技能
```

> 目录将随着内容积累逐步完善；暂未创建的分类目录会在加入对应内容时建立。

## 当前 Skill

### Web Design Radar

`skill/web design radar/`

自动发现并分析优秀网站，记录首页整体前端技术和各个 Section 的实现方式，同时整理截图、交互录屏、3D 模型、贴图及其他复刻所需资源，最终生成以中文为主、可供 Agent 后续参考的 Markdown 文档。

## 目标

让优秀网页设计不只停留在灵感收藏，而是转化为可检索、可理解、可验证、可复刻的设计与前端知识。
